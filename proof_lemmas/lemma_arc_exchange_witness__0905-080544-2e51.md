# Lemma `arc_exchange_witness` (open — conjecture + dual-attack probe; the Tutte-port answer to the branch-vertex program)

**Statement.** Let $G$ be a connected cubic $\{C_4, C_8\}$-free graph on
$n$ vertices, $24 \le n \le 32$. Let $C$ be a chordless $16$-cycle of
$G$ and let $v \notin V(C)$ be a $0$-spoke outside vertex of $C$ (no
neighbour of $v$ lies on $C$). Then $G$ contains a **chorded**
$16$-cycle $C'$ with $v \in V(C')$ and $E(C') \cap E(C) \ne \emptyset$.

**Provenance.** Queued as Q0905-082429-1 by the 2026-09-05 ideation
panel (analogy-miner slot: a port of the bridge/arc-exchange skeleton of
Tutte's theorem that 4-connected planar graphs are Hamiltonian; RIGOR
and UPSIDE crown, 9/10 each). The $0$-spoke vertices of the branch-vertex
program are exactly Tutte's *bridge interiors* for the fixed cycle $C$;
the exchange move swaps an arc of $C$ between two attachments for a path
through the bridge. In $\theta$-language: a chorded $C_{16}$ is exactly a
$\theta(1, b, c)$ with $b + c = 16$ (this is `c16_chord_equiv`), so the
lemma asserts every ($C$, interior $v$) pair admits an exchange landing
on total length exactly $16$ with the branch path hitting $v$.

**Why this closes the k >= 1 branch if proved.** The zero-free
completion (R66–R71) covers every chordless $C_{16}$ whose spokes touch
ALL outside vertices ($k = 0$). This lemma covers every chordless
$C_{16}$ with $k \ge 1$ zero-spoke vertices. Together: in ANY class
member on $24 \le n \le 32$ that contains a $C_{16}$ at all, there is a
chorded $C_{16}$ — supply $\ge 1$, no enumeration needed. A supply
falsifier would then have to contain NO $16$-cycle whatsoever, i.e.
falsify `c8free_c16_floor` outright — and such a graph at $n \le 30$ is
a complete EGC witness (32/64-cycles vacuous below $n = 32$). The
supply question and the witness question fuse.

**The crux (predicted failure point, stated up front).** If the
exchange bypasses complementary arcs of lengths $a + b = 16$ via an
interior path of length $c$ through $v$, the two candidate cycles have
lengths $a + c$ and $b + c$; a $16$-cycle appears **iff $c \in \{a, b\}$**.
$C_8$-freeness forbids only $a + c = 8$ and $b + c = 8$; nothing yet
forces $c \in \{a, b\}$. Any proof must either (i) show the menu of
available $(a, b, c)$ triples at a $0$-spoke vertex always contains a
matching one (ear-geometry + counting pressure: $16$ spokes on
$\le n - 16 - k$ touched vertices), or (ii) find the witness through a
longer composition chain (`share1_c16_compose` gives single cycles from
share-1 pairs). A falsifier is a class member with a (chordless $C$,
interior $v$) pair whose every exchange misses length $16$.

**Dual-attack record (probe BEFORE proof effort, per standing policy).**

1. **T(Petersen)**, $n = 30$ (CHECK 1): $165$ $C_{16}$s, $15$ chordless,
   $90$ ($C$, $v$) pairs — all pass. (Re-derivation of the proposer's
   probe on an independent code path; all $15$ chordless $C_{16}$s have
   exactly $k = 6$, so the $k = 0$ completion never applies to them —
   this graph is pure $k \ge 1$ territory.)
2. **The R71 anchored slice** (CHECK 2): the $10$ class members of the
   $n = 30$ $(2, 2, 1^{12})$ structure-$j{=}12$ prefix-$(0,1,3)$ corner
   (regenerated by the same enumerator as
   `c16_n30_two_apex_closed` CHECK 1, counts reproduced exactly:
   $184$ configs, $10$ members) — $1{,}588$ ($C$, $v$) pairs across
   $537$–$687$ $C_{16}$s per member — all pass.
3. **Random-walk hunt** (documented, not a CHECK — nondeterministic
   wall-clock): double-edge-swap walk inside the clean class from the
   $11$ seeds above, $240$ s: $7{,}937$ accepted $\{C_4, C_8\}$-free
   states at $n = 30$, $1{,}065{,}245$ ($C$, $v$) pairs tested,
   **zero violations**. Script archived in the session scratchpad
   (`r72_probe.py`, `r72_hunt.py`).

The T(Petersen) uniformity warning from the proposer (every exchange
there shares exactly $8$ edges — a $\theta(8,8,8)$ symmetry artifact)
does NOT survive the slice probe: the $10$ members are asymmetric
path-outside graphs and pass with heterogeneous share patterns. The
lemma is behaving like a theorem, not a symmetry accident.
